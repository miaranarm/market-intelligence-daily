Scénarios et liste de surveillance

Le momentum se prolonge : le VIX reste contenu autour de 18,6, les rendements ne dépassent pas 5,10 % et le dollar reste stable près de 103,2. Les indices progressent avec une participation large entre secteurs.

Scénario B — consolidation

Les indices marquent une pause : les gains récents se digèrent, le VIX remonte légèrement au-dessus de 18,6. Les hausses rapides sont souvent suivies de phases latérales.

Scénario C — choc de volatilité

Une surprise de taux, une tension géopolitique ou budgétaire, ou un événement de crédit fait bondir le VIX, rompt les corrélations habituelles et provoque un mouvement refuge (dollar, yen, franc suisse, or, emprunts d'État).
