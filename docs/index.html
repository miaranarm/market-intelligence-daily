Ces scénarios sont conditionnels : ils décrivent ce qu'il faudrait observer, pas ce qui va se produire. Les niveaux cités sont les niveaux actuels, utilisés comme repères d'invalidation.

Le scénario de baisse serait renforcé si le VIX dépasse durablement son niveau actuel de 20,8, si les rendements à 10 ans remontent au-dessus de 4,95 % et si le dollar se raffermit près ou au-dessus de 101,9.
